# Square-wrapped VML picture in a footer, compatibility mode 12

Reproducer for a footer whose only paragraph holds a VML picture placed absolutely
(`position:absolute`, centred, `margin-top:0`, no `mso-position-vertical-relative`, so it is
placed from its paragraph) with `<w10:wrap type="square"/>`.

`make_vml_footer_wrap.py` writes the four `.docx` files byte by byte as WordprocessingML and VML
(ECMA-376 Parts 1 and 4) with the Python standard library. No word processor and no
python-docx are involved. The text is invented, and the picture is a flat grey PNG that the
script generates.

```
python make_vml_footer_wrap.py OUT_DIR
```

| file | footer picture | compatibility mode |
|---|---|---|
| `footer-square-legacy.docx` | square wrap | none stated: `w:compat` holds only legacy options, so the document is laid out as Word 2007 (mode 12) |
| `footer-nowrap-legacy.docx` | no `w10:wrap` | the same |
| `footer-square-m15.docx` | square wrap | 15 |
| `footer-nowrap-m15.docx` | no `w10:wrap` | 15 |

The body is 36 lines, 8 empty paragraphs and 30 more lines, all at multiple 1.15 with no space
after. Page 1 ends inside the run of empty paragraphs.

Provenance: generated by the committed script from its own inputs (clean-room standard,
fixtures, case 1). License: the repository's.
